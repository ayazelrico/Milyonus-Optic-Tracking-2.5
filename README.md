# Milyonus Optic Tracking v3.0 — 90-Day Hustle Plan

The essence of this plan is simple: **No random feature additions. Every day has one measurable and clearly defined step.**

MediaPipe is only our infrastructure layer; the real value will be the **Proprietary Intelligence Layer** we build on top of it.

## 🚀 Six-Phase Roadmap

- **Phase 1 (Days 1–15): Measurement Foundation** — Stabilize the measurement system and baseline: jitter, smoothing, confidence, and unified signals.
- **Phase 2 (Days 16–30): Tracking Intelligence** — Read how a face moves over time: velocities, accelerations, gaze transitions, and focus episodes.
- **Phase 3 (Days 31–45): Behavioral Intelligence** — Move from “Where is the face?” to “How does the face behave?” with personal deviation, posture patterns, event timelines, and session summaries.
- **Phase 4 (Days 46–60): Personalization** — Move from fixed thresholds to personalized calibration: calibration mode, camera/distance compensation, and quality scoring.
- **Phase 5 (Days 61–75): Performance & Reliability** — Make the system production-grade: separate rendering from inference, introduce worker architecture, test for memory leaks, and add error recovery.
- **Phase 6 (Days 76–90): Product Intelligence** — Turn the technical demo into a product: dashboard, heatmaps, automated insights, developer API, SDK, and the v3.0 review.

## 🔥 Daily Work Cycle (Hustle Rule)

Every day, we will follow this clear nine-step formula:

1. **Observe:** Find a missing or inaccurate metric.
2. **Hypothesis:** State what will improve if we make the change.
3. **Implement:** Make one small change, with a maximum target of 30 minutes to 3 hours.
4. **Test:** Test with a real camera.
5. **Measure:** Compare the result with the previous version.
6. **Commit:** One logical change equals one commit, using `feat`, `fix`, `perf`, or `refactor` as appropriate.
7. **Record:** Complete the daily template: objective, change, metric, and result.

> **Golden Rule:** If you cannot answer the question “Which measurement does this feature improve?”, no code will be written that day.
